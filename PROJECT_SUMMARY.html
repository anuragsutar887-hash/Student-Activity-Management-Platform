2. User Roles & Accounts

A. Student Credentials (68 Pre-seeded Profiles)

  • Login: Select profile from student dropdown, enter PRN and password.
  • Compulsory PRN: Validates uniqueness across all 68 students. If another student's PRN is used, fails with PRN is wrong. PRN "..." is already registered to another student (...).
  • Default Passwords: Pass@01 to Pass@68 matching Roll No C01 to C68.
  • Example: Anurag Sutar (Roll: C60, Default PRN: PRN2024IT060, Password: Pass@60).

B. Faculty / Staff Coordinator

  • Email: faculty@itpulse.edu (or teacher@itpulse.edu)
  • Password: Teacher@IT2026!
  • Capabilities: Activity queue review, 1-click verify/reject, academic groups oversight, student directory.

C. System Administrator

  • Email: admin@itpulse.edu
  • Password: Admin@IT2026!
  • Capabilities: Full institutional dashboard, student & staff management, category configuration, audit logs.

3. Visual Theme Architecture & Tailwind v4 Guide

The application runs on Tailwind CSS v4 with custom variables and a root .dark class.

  • Context: ThemeContext.jsx stores mode in localStorage.getItem('itpulse-theme') and toggles document.documentElement.classList.
  • Dark Variant: In frontend/src/index.css: @custom-variant dark (&:where(.dark, .dark *)); enables all dark: utilities.
  • Theme Toggle: Header contains a Sun/Moon button connected to useTheme().toggleTheme.
Theme Rules to Avoid "Color Patches":
  1. Always pair bg-white with dark:bg-slate-900 or dark:bg-slate-800/60.
  2. Always pair border-slate-200 with dark:border-slate-700 or dark:border-slate-800.
  3. Always pair text-slate-900 with dark:text-slate-100.
  4. Form inputs must include dark:bg-slate-800 dark:text-slate-100 dark:border-slate-700.

4. Core Portal Workflows

A. Student "Add Achievement" Workflow

  • Label Standard: All occurrences of "Add Activity" renamed to "Add Achievement" in Student navigation, buttons, and headers.
  • Compulsory Certificate: Uploading certificate/proof is mandatory for submission (marked with a red asterisk *). Clicking Submit without a certificate displays an error blocking submission.
  • Seeded Peer Activities: New accounts immediately see 6 verified IT peer achievements (Hackathons, AWS certifications, IEEE paper, etc.) loaded from PREVIOUS_ACTIVITIES in activityService.js (v11 storage).

B. Faculty Review & Verification

  • Review queue provides 1-click verification or rejection with feedback instructions.
  • In-modal PDF and image certificate viewer (CertificateModal.jsx) with zoom and print options.
  • Academic groups view (MyGroups.jsx) for cohort monitoring.

C. Charts & Responsiveness

  • Recharts Optimization: BarCharts use isAnimationActive={false} and maxBarSize={36} to prevent lag; PieCharts use paddingAngle={0} and stroke="none" to remove gaps.
  • Responsive Design: Dual table and mobile-card views across dashboards and browsers.
